🌐 Graphs in Java

This folder contains Java programs covering basic and advanced concepts of Graph Data Structures and Graph Algorithms.

📚 Topics Covered

1. Graph Basics

- Graph Creation using Adjacency List
- Breadth First Search (BFS)
- Depth First Search (DFS)

2. Graph Problems
- Connected Components
- Cycle Detection in Undirected Graph
- Cycle Detection in Directed Graph
- Bipartite Graph
- Topological Sorting

💡 Concepts Learned

- Vertices and Edges
- Adjacency List Representation
- Graph Traversal
- BFS using Queue
- DFS using Recursion
- Visited Array
- Cycle Detection
- Graph Coloring
- Topological Ordering

🛠️ Technologies Used

- Java
- Data Structures and Algorithms

🎯 Learning Goals

- Understand graph representation and traversal.
- Implement BFS and DFS algorithms.
- Solve important graph-based problems.
- Learn cycle detection and bipartite graph checking.
- Understand topological sorting and its applications.
