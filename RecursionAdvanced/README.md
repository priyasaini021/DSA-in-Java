Advanced Recursion in Java

This folder contains Java programs to practice recursion concepts in Data Structures and Algorithms (DSA).

Topics Covered

1. Tiling Problem – Count the number of ways to tile a 2 × n floor using 2 × 1 tiles.
2. Remove Duplicates – Remove duplicate characters from a string while preserving the original order.
3. Friends Pairing Problem – Count the possible ways for friends to remain single or form pairs.
4. Binary Strings – Generate binary strings without consecutive 1s.
