Stack in Java

This folder contains Java programs based on the Stack Data Structure.

Topics Covered

1. Valid Parentheses
2. Duplicate Parentheses
3. Maximum Area in Histogram

Concepts Used

- Stack Data Structure
- Push and Pop Operations
- LIFO (Last In, First Out)
- Next Smaller Left (NSL)
- Next Smaller Right (NSR)
- Array and Stack Operations

Programs Description

Program| Description
ValidParentheses.java| Checks whether brackets are balanced or not.
DuplicateParentheses.java| Checks whether an expression contains duplicate parentheses.
MaxAreaHistogram.java| Finds the maximum rectangular area in a histogram.

Language Used

- Java
