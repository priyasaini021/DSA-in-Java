Queue in Java

This folder contains Java programs based on the Queue Data Structure.

Queue follows the FIFO (First In, First Out) principle.

Topics Covered
1. First Non-Repeating Character
2. Queue Reversal
3. Deque Using JCF
4. Queue Using Deque
5. Interleave Two Halves of Queue

Concepts Used

- Enqueue and Dequeue
- FIFO Principle
- Circular Queue
- Deque (Double Ended Queue)
- Stack and Queue Operations

Language Used

- Java

Purpose: To understand Queue implementations and improve problem-solving skills.
