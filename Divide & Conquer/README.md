Divide and Conquer in Java

This folder contains Java programs to practice the Divide and Conquer technique in Data Structures and Algorithms (DSA).

Topics Covered

1. Merge Sort – Sort an array using divide and conquer.
2. Quick Sort – Sort an array using partitioning.
3. Search in Rotated Sorted Array – Find an element using binary search.
5. Inversion Count – Count pairs where the earlier element is greater than the later element.


Language

Java
