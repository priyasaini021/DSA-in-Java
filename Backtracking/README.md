What is Backtracking?

Backtracking is an algorithmic technique that builds a solution step by step. If a choice does not lead to a valid solution, the algorithm goes back and tries another choice.

Learning Goals

- Explore all possible solutions to a problem.
- Practice solving constraint-based problems.
